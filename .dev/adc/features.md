## 1. Scope & Role Classification Capabilities

| Capability | Behavior |
| --- | --- |
| **Worktree Diff (`--base <ref>`)** | Diffs `<ref>` against working tree (staged + unstaged) with `--ignore-space-at-eol` (`W1`), plus untracked non-ignored `.py` files. |
| **Exact Commit Range (`--base <ref> --tip <ref>`)** | Diffs `<base>..<tip>` purely from Git object store (`git diff` + `git show` + `git ls-tree`/`cat-file --batch`), ignoring working tree edits. |
| **Branch Divergence (`--base <ref> --merge-base [--tip <ref>]`)** | Resolves `git merge-base <base> <tip>` (defaulting `<tip>` to `HEAD`) before diffing. |
| **Path Audit (`--paths <p1> ... [--repo <root>]`)** | Scans explicit files/directories on disk; infers single Git worktree root when all paths share one repo, or falls back to `os.path.commonpath`. |
| **Default Exclusions (`SKIP_SEGMENTS`)** | `.git`, `.hg`, `.svn`, `.venv`, `venv`, `node_modules`, `__pycache__`, `build`, `dist`, `.scratch`, `.tox`, `.mypy_cache`, `.pytest_cache`, `.ruff_cache`, plus `--exclude <GLOB>`. |
| **Test vs. Production Role (`role`)** | Any path with `test` or `tests` directory segments, or matching `test_*.py`, `*_test.py`, `conftest.py`, `*_test_support.py`, or `--test-glob <GLOB>` is `"test"`; all others are `"prod"`. |
| **Worker Concurrency (`--jobs <N\|auto>` / `-j <N\|auto>`)** | Defaults to `auto` (`min(os.process_cpu_count() or 1, 8)`); parallelizes per-file Git diff/blob reads and AST indexing across Stages 1–3 via `parallel_map` with deterministic input-order preservation and runtime-aware GC (`_FREE_THREADED_GC`). |

## 3. High-Volume Evidence Contracts (`v0.5`)

`PY01` uses the registry templates `PY01_bundle_site` (`:{line} {code}`), `PY01_bundle_inner` (` [inner: {code}]`), and `PY01_bundle` (`{count} sites: {sites} | {receivers}`). The transient `_reflect` key carries column bounds and the unparsed call, enabling quote-insensitive nested receiver deduplication before the covering span is widened. It is removed before public output. Compact rendering suppresses bundled `PY01` / `PY04` `Code:` only when `evidence.split(" sites: :", 1)[0].isdigit()`; singleton union-annotated receiver evidence retains `Code:`.

`PY02` non-raising handler evidence applies these mutually exclusive strata in order:

| Template | Evidence | Condition |
| --- | --- | --- |
| `PY02_silent_pass` | `silent-pass` | Only `pass` / `...` / `continue` / `break`, ignoring string-expression documentation. |
| `PY02_returns_fallback` | `returns-fallback: {value}` | Local return expressions (bare return is `None`), unique in source order and joined by `, `; values longer than 80 characters become `value[:77] + "..."`. |
| `PY02_fallthrough_exc_info` | `fallthrough-logged-exc-info` | Local `.exception` / traceback-printing or formatting call, or an `exc_info` keyword, unless that call explicitly disables it with constant `False` / `None` / `0`. |
| `PY02_fallthrough_no_tb` | `fallthrough-no-traceback` | Remaining non-raising handlers. |

Nested function/class/lambda returns and calls do not affect the handler stratum. These are mechanical facts, not severity judgments. The paths population is `353 / 330 / 151 / 549` respectively, plus `1` unchanged `NoReturn`-only record; all `59` historical paired-validation handlers match their coarse strata (`4` pass, `9` return, `46` fallthrough).
