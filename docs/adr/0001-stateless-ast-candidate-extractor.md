# Stateless AST Candidate Extractors Over Stateful Ratchet Linters

Language scripts under `engineering/anti-defensive-coding/scripts/` (starting with `scan_python.py`) are stateless, diff-aware **Candidate Extractors** that exit `0` on completed scans and emit structural candidates paired with local contract evidence and verification questions for a **Goldfish Reviewer**, rather than acting as deterministic pass/fail linters or writing `.checkup` baseline files into target repositories (exiting `2` only on invalid CLI arguments, missing target paths, or unresolvable Git references). Standard linters and typecheckers (`ruff`, `clippy`, `pyright`, `mypy`) already own deterministic single-node syntax and style diagnostics (such as 2-argument `getattr`, ordinary unused parameters, and bare `# noqa` / `# type: ignore` counts); the extractor skips those diagnostics and focuses on defensive patterns that evade default lint rules or require multi-statement control-flow, pre/post-diff comparison, diff-anchored `prod ↔ test` reachability, or 1-hop caller/producer contract judgment to confirm.
