# 文档审查优先级：能力范围

状态：v0.1 范围已确认，详细排序、输入输出及验收见本地规格 `.scratch/doc-audit/spec.md`；以下不代表已实现。

## 输出定位

提供有证据的文档维护优先级与问题发现。v0.1 的分层图辅助解释导航结构，桑基图及后续 agent 支持见 [roadmap.md](roadmap.md)。

输出分为 Document Review Queue（待审文档队列）和 Documentation Improvement Queue（问题改进队列）。前者依据访问证据与导航重要性分配审查精力；后者以已确认问题的后果优先，影响范围辅助排序。两者不合成一个总分，未审查不等于健康。

首页以待审文档队列和已确认问题队列为主，分层图作为关联视图一键切换。列表可定位节点，节点可查看对应问题与导航关系；保留暗色主题、搜索框和侧边详情栏。大小与颜色表达所选指标，徽标表达审查状态；无动态数据时明确显示静态指标，不混称真实热度。

动态证据来自代表性任务的只读试跑，统计实际工具行为，不依赖试跑最终回答。报告展示实验任务及来源，不将实验触达解释为日常使用频率。

## 审查范围

| 类别 | 问题范围 |
| --- | --- |
| 引用有效性 | 引用文件、锚点及目标是否有效 |
| 内容准确性 | 接口、命令、流程是否与当前代码一致 |
| 导航有效性 | 入口与指针是否明确表达何时应读取目标材料 |
| 文档组织 | 重复、冲突及不必要的常驻上下文负担 |

发现需要证据和可理解的影响说明。纯审美润色不单独构成问题。本 skill 不执行修复。

## 默认审查预算与完成标准

对整个扫描范围执行确定性检查，例如可确认的失效文件引用；按队列默认深审 10 份文档，调用时可调整数量。查证所需的源码与关联文档可以读取，但不自动将它们扩展为新的深审对象。

报告展示已审、未审及下一批候选；进一步深审由用户要求继续。

默认 10 份分为 8 份主队列和 2 份盲区检查。主队列优先纳入所选 agent 的有效自动加载入口；其余有动态数据时按实验触达指标降序，同等指标或没有动态数据时依次考虑导航咽喉程度、距入口远近、不同来源文档的引用数。读取次数用于解释反复翻阅，不作为主要排序依据，不引入加权总分。实验触达有效性与分母见 [architecture.md](architecture.md)。

盲区优先检查入口不可达文档，其次低访问文档，组内用不同来源文档的引用数辅助选择。报告解释每份文档入选理由。文档去重，某组不足时将剩余名额交给另一组；入口超过预算时不突破预算，明确显示未审部分。非默认预算按约 20% 留给盲区，预算为 1 时全部交给主队列；确定的取整、补位和稳定排序规则以规格为准。

每份深审文档检查四个审查维度。进度分为未审、审查中、已完成、受阻；已确认问题与待核实项分开。无发现只表示本次未发现问题，不保证正确。每条发现包含问题位置、核查依据、影响说明与建议方向，一份文档允许多条发现；未能核实的部分明确记录。

查证以读取代码和配置为主，不因文档引用命令就执行；需要执行才能验证时，先说明验证方法及风险。

## 问题改进队列的后果分级

| 等级 | 判断依据 |
| --- | --- |
| 高 | 有证据支持的数据损失、安全风险，或关键工作流被错误指引 |
| 中 | 导致任务失败、错误实现、明显返工，或重要资料无法被正确找到 |
| 低 | 局部导航阻力、重复维护负担、非关键的不一致 |

等级内按影响范围辅助排序。纯猜测单列待核实项，不进入已确认问题队列；不能仅凭文档涉及安全或部署就判高。

## 扫描范围的选择

由 agent 根据仓库用途判断哪些目录包含长期维护的开发文档，哪些主要是一次性工作记录，再向脚本传递明确的扫描目录。脚本执行选定范围，不承担语义分类。目录名称不是通用判据；本仓库的 `.scratch` 是一次性工作记录的例子，不构成其他仓库的硬编码排除规则。

agent 先查看目录结构和已有入口说明，必要时抽样阅读，再选择目录、单独文件和排除项。脚本支持这三种范围输入；报告展示最终范围及简短理由。能够判断时直接执行，仅在用途不明且明显影响范围时询问用户。

范围外引用检查目标是否存在并标记为范围外，不自动递归扩大扫描范围；未纳入审查不等于死链。v0.1 支持 `.md`、`.markdown`，其他格式延期；不主动联网检查外部 URL。

试跑探索范围与文档审查范围分开：子代理按真实任务及正常工具权限探索，不接收入选文档清单或目录限制。范围外文件访问仍记录为行为证据，但不自动扩展深审范围；报告显示实验触达的范围外材料，由用户决定是否纳入审查。

## 入口选择

agent 根据所选工具的加载规则及仓库说明选出自动加载入口和导航入口，可补充项目特有入口。自动加载入口标注为规则推定，不伪造历史读取次数；README 或文档索引等导航入口不声称自动加载。图允许多个入口，按所选入口计算距离并展示入口类型。

## 静态引用证据

明确引用包括 Markdown 链接和具有明确工具语义的导入；无法解析到目标时可报告失效引用。路径提示包括反引号或正文中的文件路径，明确定位后展示提示边；无法定位或存在多个候选时交给 agent 判断，不直接报死链，不猜同名目标。

静态距离和咽喉指标默认依据明确引用，路径提示经 agent 确认后才纳入计算。低置信度提示不制造确定的可达性。

## 静态模式与实验缺口

无可用实验行为证据时，仍按入口距离、引用关系和导航咽喉提供静态审查流程。动态指标显示无数据或不支持，不以零值或静态分数冒充真实访问统计。

部分实验轨迹可用时显示任务范围与缺口；采集或解析失败不得呈现为未读取。实验行为证据是增强信息，不是静态审查的前置条件。
