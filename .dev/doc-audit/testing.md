# 文档审查优先级：验证计划

状态：尚无实现、测试命令或通过结果。可观察验收矩阵 T01–T19 已记录于本地规格 `.scratch/doc-audit/spec.md`；本文件保留验证风险与测试工作流背景。

## 研究留下的验证缺口

- 当前环境是否可获得本次试跑的实际工具调用与结果，临时解析器能否正确归属路径、调用身份和返回内容；回答里声称读取不能制造访问事件。
- 静态指针提取的准确性：明确链接、路径提示、重复文件名、入口不可达分量和循环引用。
- 排序能否解释优先级，以及任务选择、重复试跑和部分失败是否扭曲实验触达指标。
- 分层图在多入口、共享文档、回边及较大文档集合中的可读性。
- 本地资产与敏感文本展示的安全性，以及报告所声称的离线能力。
- 指定任务集和环境下的首屏时间、试跑耗时、模型资源及内存；未实测前不承诺“任意仓库几秒完成”。

实验规模、聚合口径及能力预检已在规格中落为可观察验收条件。当前未运行试跑或性能测试；历史解析研究不等于新实验方案已获验证。

## 首发验证重点

- 行为证据链：实际只读试跑的调用与结果能转换为事件并回查；最终回答提及但未实际读取的文件不得增加计数。
- 实验有效性：正常且可分析的零文档访问样本仍计分母，中断与不完整样本分开，无有效样本明确使用静态排序。
- 环境与隔离：验证预检结论、停止控制及目标工作树未被修改；记录实际继承上下文，不以提示词宣称替代验证。
- 导航与排序：共享节点、回环、范围外目标和模糊路径不伪造可达性；队列入选理由可由证据和既定排序解释。
- 报告生命周期：审查结果局部更新、关闭服务后的自包含快照、敏感文本安全显示及证据变更后的待复核状态。

上述重点对应规格的验收矩阵，尚无已通过结果，也未设未经测量的秒级性能承诺。测试沿用仓库 CLI/JSON 与只读工作树的行为验证先例，不锁死内部实现或提示词字面量。
