# Lean Axis: Python Diagnostic Patterns

Load this reference only when the reviewed diff (or its directly affected callers/tests) touches Python code. Apply these recognition patterns under the first-principles gates and grading rules in `SKILL.md`.

## 1. Reflection, Dict Indexing & Runtime Constant Checks

- **Reflection on owned classes (`#10`)**: Calling `getattr(obj, "attr", None)` or `if not hasattr(self, "cache"): self.cache = {}` on classes defined in this repository. → Declare attributes explicitly in `__init__` or `@dataclass` and access `obj.attr` directly.
- **Required-key `.get()` vs discriminated unions (`#1`)**: Calling `row.get("key")` on required keys of fixed-shape internal dicts. → Index `row["key"]` directly; if a test fixture omits a required key, fix the fixture. *Discriminated-union caveat*: When a dict varies by a discriminant key (e.g. `kind == "local" | "remote"` where only `"local"` carries `memory_mb`), narrow on the authoritative discriminant first (`if row["kind"] != "local":`), then index `row["memory_mb"]` directly; never replace discriminant narrowing with `.get("memory_mb")`.
- **Import-time constant self-checks (`#22a`)**: Running a `_check_descriptors()` validator at module import time to check the keys/types of a hardcoded static dict literal defined right above it. → Delete runtime import self-checks on static literals.
- **Linear scans over static spec tuples (`#22b`)**: Scanning a static tuple linearly on every `get_spec(key)` call instead of prebuilding a module-level `_SPEC_BY_KEY` lookup dict at import time. → Prebuild the $O(1)$ module-level dict.

## 2. Exception Washing & Default Shadowing

- **Broad internal `except` (`#16`, `#27a`, `#37`)**: Wrapping internal typed computation in `except (AppError, ValueError, TypeError, KeyError, OverflowError):`—or migrating/copy-pasting that broad catch into downstream callees/constructors during a refactor—turning attribute/key typos and contract bugs into business fallbacks. → Restrict `try/except` to external parse/I/O boundary operations with exact exception types; delete broad `KeyError`/`TypeError` catches on internal structures.
- **Default substitution shadowing validation (`#18`)**: Calling `start = parse_hhmm(val, allow_none=False)` (which silently returns `"08:00"` on missing input) and then writing `if start is None: raise ValidationError(...)` on the next line. → Validate raw un-defaulted input (`allow_none=True` then raise on `None`) before applying defaults.
- **Double bunker & self-throw-catch (`#19b`, `#32b`)**: Wrapping `parse_float(..., fallback=0.0)` in an outer `try/except` that repeats the same fallback; or writing `if logger.write() is False: raise RuntimeError(...)` followed immediately by `except Exception:` in the same function while all callers discard the boolean return. → Rely on the callee's contract; delete outer duplicate catches and self-throw-catch wrappers.

## 3. Linter Evasion, Type Silencing & Hidden State

- **Explicit linter silencing & entry overwrite (`#21b`, `#33`, `#42`)**: Silencing `unused-argument` warnings via `_ = param`, overwriting a parameter on line 1 (`metrics_by_id = prepared["metrics"]`), or passing a pre-extracted slice `w_timeline` from all callers while keeping the parent `worker_timeline` parameter with an unreachable `if w_timeline is None: w_timeline = worker_timeline.get(...)`. → Remove the dead/overwritten parameters from the signature and all callers.
- **Base-class `Optional = None` + `cast(...)` (`#27d`)**: Adding `Optional = None`, `if self.attr is not None else ...` fallback recomputation, and `typing.cast(...)` on a production base class because one subclass or test fixture omitted a required attribute. → Initialize the attribute in the subclass `__init__` or test fixture; keep the production attribute non-optional.
- **Callable attribute piggybacking & transient `with`-state (`#29`, `#40`)**: Attaching state or secondary functions onto a function object (`fn.prepared = ...`) and branching via `getattr`, mutating `facts["reader"] = reader` to smuggle a DB/service instance into a pure projection dict, or setting `self.active_codes = ...` inside `with service.read_snapshot():` and resetting it to `None` in `finally:`. → Pass explicit typed parameters and structured/dataclass return values; complete validation in the read phase.
- **Monkeypatch sync trampolines & identity checks (`#28`)**: Maintaining `_sync_runtime_hooks()` in a facade module to copy attributes into submodule globals on every call, or branching on `if fn is not _DEFAULT_FN:` in production code to detect test monkeypatching. → Delete runtime monkeypatch syncers and identity checks; in tests, patch the namespace where the symbol is looked up or inject dependencies explicitly.

## 4. Copy, Cache & Loop Churn

- **`dataclasses.asdict()` & row-copy churn (`#20b`, `#23b`)**: Calling `dataclasses.asdict()` repeatedly on an immutable scalar dataclass, or wrapping `self.fetchall()` (when the base repository already returns fresh `dict`s) in `[dict(row) for row in self.fetchall()]`. → Access scalar attributes directly and trust fresh repository containers.
- **Cache-hit write-back & double `@cached_property` (`#21a`, `#31b`)**: Reading a hit from a cache dict and writing the same value back into the dict, or wrapping an already `@cached_property` attribute in a second single-line `@cached_property` on the same or child class. → Return directly on cache hit; access the existing cached property directly.
- **Hot-loop single-key dict wrapping & throwaway closures (`#20c`, `#35`)**: Allocating `{rank_field: cache[rank_field][item_id]}` on every inner-loop iteration just to satisfy an old `Mapping[str, Any]` helper signature, or defining a zero-arg closure `def cached(): ...` inside a hot loop and calling it once on the next line. → Change the helper signature to accept `(value, field_name)` scalars and call methods directly.
- **Test-only `.apply()` leftovers & single-consumer `*_test_support.py` (`#41`, `#43`)**: Keeping a 0-production-caller monolithic `.apply()` on services after production migrated to `prepare + apply_prepared` solely for legacy tests, or creating a single-consumer `*_test_support.py` that asserts private `._legacy_*` methods. → Delete `.apply()` and migrate tests to `prepare + apply_prepared`; inline small single-file fixtures and assert public APIs.
