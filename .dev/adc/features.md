# ADC Feature & Probe Capability Matrix (`v0.4.4`)

This document tracks the user-observable extraction capabilities, active probe arms, noise-suppression guards, and bundling rules of `engineering/anti-defensive-coding` as of `v0.4.4`; volume columns retain the historical `v0.3` benchmark counts. Verification prompts appear once per short key in the compact `Verification Legend`, while JSON retains each candidate's static `verify` text.

---

## 1. Scope & Role Classification Capabilities

| Capability | Behavior |
| --- | --- |
| **Worktree Diff (`--base <ref>`)** | Diffs `<ref>` against working tree (staged + unstaged) with `--ignore-space-at-eol` (`W1`), plus untracked non-ignored `.py` files. |
| **Exact Commit Range (`--base <ref> --tip <ref>`)** | Diffs `<base>..<tip>` purely from Git object store (`git diff` + `git show` + `git ls-tree`/`cat-file --batch`), ignoring working tree edits. |
| **Branch Divergence (`--base <ref> --merge-base [--tip <ref>]`)** | Resolves `git merge-base <base> <tip>` (defaulting `<tip>` to `HEAD`) before diffing. |
| **Path Audit (`--paths <p1> ... [--repo <root>]`)** | Scans explicit files/directories on disk; infers single Git worktree root when all paths share one repo, or falls back to `os.path.commonpath`. |
| **Default Exclusions (`SKIP_SEGMENTS`)** | `.git`, `.hg`, `.svn`, `.venv`, `venv`, `node_modules`, `__pycache__`, `build`, `dist`, `.scratch`, `.tox`, `.mypy_cache`, `.pytest_cache`, `.ruff_cache`, plus `--exclude <GLOB>`. |
| **Test vs. Production Role (`role`)** | Any path with `test` or `tests` directory segments, or matching `test_*.py`, `*_test.py`, `conftest.py`, `*_test_support.py`, or `--test-glob <GLOB>` is `"test"`; all others are `"prod"`. |
